# To-Do List Application

A dynamic and interactive to-do list application built using JavaScript. The app allows users to add, edit, and delete tasks while maintaining a simple and user-friendly interface.

**Live Link:** [To-Do List Application](https://nauman-ishaq-brainx.github.io/To-Do-list-JS/)

---

## 🚀 Features

- **Task Addition:**  
  - Add new tasks by entering text and pressing the **Enter** key.  

- **Task Completion:**  
  - Mark tasks as completed using checkboxes.  
  - Completed tasks are visually distinguished using a line-through effect.  

- **Task Editing:**  
  - Edit existing tasks by clicking the edit icon.  
  - The input field is auto-focused, and the cursor is positioned at the end of the text for easy editing.  

- **Task Deletion:**  
  - Remove tasks by clicking the delete icon.  

- **Dynamic Task List:**  
  - The list is dynamically updated to reflect the current state of tasks (added, edited, or deleted).  

---

## 🛠️ Usage

- Open the live link and add tasks by entering text and pressing **Enter**.  
- Click the checkbox to mark a task as completed, which applies a line-through style.  
- Click the edit icon to modify a task. The input field is focused automatically, and the cursor is placed at the end of the text.  
- Click the delete icon to remove a task from the list.
